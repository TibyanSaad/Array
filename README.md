# Simple Customer Ticketing System (Java)

## Overview
This project is a simple **console-based ticketing system** written in Java.  
It allows customers to submit feedback (tickets), update existing tickets, and delete tickets. The system demonstrates basic array handling, user input, and CRUD operations in Java.

## Features
- Collects **3 feedback entries** from the user
- Displays all submitted feedback
- Allows the user to:
  - **Update** a ticket by index
  - **Delete** a ticket by index
- Shows updated or deleted ticket lists
- Runs entirely in the console with interactive prompts

- `CustomerTicketingSystem.java` → Main program file
